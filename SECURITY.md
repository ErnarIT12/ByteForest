# Security Policy

## Supported versions

Only the latest release of ByteForest receives security fixes.

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately in one of these ways:

- Use GitHub Security Advisories: open the [Security tab](https://github.com/ErnarIT12/byteforest/security/advisories/new) of the repository and choose "Report a vulnerability".
- Or email **175706703+ErnarIT12@users.noreply.github.com** with "ByteForest security" in the subject.

Please include the affected version, steps to reproduce, and the impact you see. ByteForest parses NTFS structures read straight from disk, so crafted or corrupted volumes are in scope, as is anything that could cause data loss or privilege problems.

You can expect an acknowledgement within a few days. Fixes are released as soon as practical and credited in the changelog unless you prefer to stay anonymous.
